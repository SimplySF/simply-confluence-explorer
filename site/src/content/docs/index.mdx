## Start it

Confluence Explorer needs Node.js 22 or later and a Confluence Server or Data Center instance. Run it
with `npx`, then open the address it prints:

```sh
npx @simplysf/simply-confluence-explorer
```

## What it does

<CardGrid>
  <Card title="Browse and read" icon="open-book">
    A space's page tree, and any page rendered, as Markdown, or in Confluence's own storage format. [Get
    started](/getting-started/)
  </Card>
  <Card title="A copy on disk" icon="document">
    Sync a whole space as Markdown files with their attachments, with a table of contents and a ZIP export. [Keeping a
    copy on disk](/guides/syncing-a-space/)
  </Card>
  <Card title="Ask an AI" icon="comment">
    Ask about a page, a page and everything under it, or a whole space, with Claude, ChatGPT or Gemini. [Asking an
    AI](/guides/asking-ai/)
  </Card>
  <Card title="Keep data in" icon="approve-check">
    Excluded pages never leave your computer, and a leak guard stops secrets and replaces personal data. [What leaves
    your computer](/guides/data-safety/)
  </Card>
  <Card title="Change pages" icon="pencil">
    Ask a chat for suggestions, tick the ones you want, review each edit, and push it without overwriting anyone.
    [Changing pages from a chat](/guides/changing-pages/)
  </Card>
  <Card title="Write new pages" icon="add-document">
    Check whether a page already covers the topic, then write it, or a series, with an AI that can read a GitLab
    repository. [Writing a new page](/guides/new-pages/)
  </Card>
</CardGrid>
