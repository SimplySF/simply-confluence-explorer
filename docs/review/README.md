# Review

A stable release ships only after a second person, not the one who opened it, approves the pull
request that releases it (ADR-044). That approval is the release's review, and GitHub keeps it with
the pull request.

This folder holds any written review a release gets beyond that: notes on what was checked before
the release, what was not checked, and what is known to be outstanding. The second and third parts
matter most, because the things nobody looked at are exactly what a reader needs to be told about.
A file here is named after the version it covers, such as `1.0.0.md`. Nothing requires one.
